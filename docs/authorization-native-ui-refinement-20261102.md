# 原生权限页面布局精修

## 已观察的问题

390 × 844 微信开发者工具模拟器中，授权规则页把新增、搜索、批量和委托拆成多张操作卡，首条规则被挤到屏幕下方。每条规则又连续放置展开、编辑、复制、删除大按钮。编辑页直接罗列 62 组资源，折叠后仍占据很长页面；授权方式与启用状态没有清晰的选中反馈。问题截图保存在本机临时目录 `native-ui-review-rules.png`、`native-ui-review-rule-actions.png`、`native-ui-review-editor-top.png`、`native-ui-review-editor-middle.png`、`native-ui-review-editor-bottom.png`。

## 本次调整

- 搜索、新增、批量操作合并到一个控制区；规则保留前 3 项能力摘要，展开后显示完整能力、对象、数据范围和字段，不减少授权信息。
- 编辑、复制和删除对照场地管理使用紧凑文字操作，分别采用浅蓝与浅红背景；删除继续进入影响确认页。委托与规则详情改为标题行展开。
- 编辑操作先按业务分组折叠，再列资源与操作；搜索只过滤可见项，不改动已选能力。允许、禁止改为明确选择，启停使用开关，数据范围显示选中状态。
- 实际权限按业务分组，搜索后自动展示匹配项；隐藏页面清理分组结果，避免旧角色资料残留。
- 条件维度标题与已选摘要分行；影响确认的前后结果手机单列、Pad 双列，操作底栏独立。

## 已完成的检查
