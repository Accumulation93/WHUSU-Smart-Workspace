# 权限与组织间复制界面精修

## 布局与控件

本轮覆盖授权列表、规则／方案／委托编辑、影响确认、组织间复制、岗位性质两端页面。列表把新增、搜索、批量操作放在同一卡片；规则只显示3项能力摘要，完整内容仍可展开。编辑先按业务模块折叠操作，再列资源和能力，搜索不更改已选值。实际权限采用同样的分组检索。

编辑、复制、删除对照场地和审核的紧凑文字操作；按用户最后反馈，编辑进一步使用灰蓝文字、接近白色的玻璃背景与600字重，复制保留浅蓝，删除保留浅红。启停使用蓝色原生开关／网页共享UiSwitch。允许与禁止通过蓝边浅蓝选中状态区分。日期与“不限制”等纵向控件由表单分组分配间距。普通页面局部覆盖，不修改全局样式或权限判断。

网页复制页3处原先缺少完整表面的选择框改用共享field-input；页签按真实数量等宽，使用共享tab-active。复制和岗位性质补齐Hero工作角色属性。所有危险操作保留原影响确认和授权检查。
