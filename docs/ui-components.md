# UI 组件清单

当前项目使用原生微信小程序组件和项目自有 WXSS，不依赖第三方 UI provider。

## 共享组件

| 组件 | 路径 | 用途 | 必须保留的差异 |
| --- | --- | --- | --- |
| `workspace-hero` | `miniprogram/components/workspace-hero/` | 品牌、姓名、身份、组织与切换入口 | 手机换行更自然，Pad 收紧内边距，横屏压缩高度 |
| `viewport-portal` | `miniprogram/components/viewport-portal/` | 将共享弹窗内容提升到视口层 | 三种设备都固定遮罩和弹窗位置；弹窗令牌由 portal 内的遮罩直接持有，不依赖页面变量继承 |
| `ui-icon` | `miniprogram/components/ui-icon/` | 统一 SVG 图标加载和色调 | 图标尺寸随语义和设备令牌调整，不用 emoji |
| `signaturePad` | `miniprogram/subpackages/audit/components/signaturePad/` | 审核签名输入 | 保留画布专用触摸锁和横向空间 |

## 状态表达

- 蓝色：当前选择、主要动作、处理中。
- 绿色：已完成、已绑定、可用。
- 橙色：待处理、需审核、提醒。
- 红色：驳回、删除、危险操作。
- 灰蓝：不可用、历史状态、弱化元数据。

状态标签是元数据，不使用原生按钮语义；只有真正可操作的元素才接受点击反馈。

按钮、页签、选择项和状态气泡统一使用柔和圆角矩形，圆角由
`--ui-control-radius` 与 `--ui-compact-radius` 按设备控制：手机主按钮
`28rpx`、紧凑控件 `18rpx`；Pad 竖屏主按钮 `14px`、紧凑控件 `12px`；
Pad 横屏主按钮与页签 `12px`、紧凑控件 `11px`。页面级 WXSS 不得用固定
数值覆盖这些令牌，也不得在可见文本控件上继续使用 `999rpx` 胶囊；头像、
加载圈、进度节点、纯图标圆钮等真正圆形元素不受此限制。

## 组件边界

- 共享组件只负责结构、视觉和交互契约，不读取具体业务接口。
- 页面负责把业务数据映射成组件需要的展示字段。
- 子应用可以拥有专用列表行，但必须复用全局字体、设备令牌、按钮角色和弹窗契约。
- 认证与恢复操作复用人事管理的搜索行、成员卡片、状态元数据和批量工具栏，不得再建立灰暗、拥挤的独立视觉体系或第二套人员目录。
- 行级状态操作通过精确的数据路径更新对应行；禁止为了更新一个按钮而重新请求或重绘整个页面。
- 不为单个页面复制 `workspace-hero`、弹窗遮罩或一套新的按钮基础样式。
- 页面 WXML 的静态间距、字号、颜色和圆角必须使用语义类；只有数据驱动的坐标、进度或动画允许动态行内样式。
- 弹窗正文不得直接贴着 `scroll-view` 边缘；功能分区按语义使用内卡，禁止每个字段套卡或清空整个正文表面。
- 普通弹窗默认只保留外壳和正文两层；正文中的唯一表单或详情包裹必须使用纯布局容器，不能重新绘制同质边框、背景和阴影。
- 弹窗壳使用设备对应的受控宽度上限，优先给表单、列表和说明留下合理横向空间；不得因变量继承失败或内容收缩而退化为窄条窗口。

## 人事治理组件

- 管理端在人事信息内只保留“成员资料 / 认证设置”两个模式。成员外卡保持简洁，只展示姓名、学号、岗位数量、资料状态和一个合并账号状态；详情摘要沿用这一状态气泡，账号与认证分区不得再用字段卡重复显示当前状态、微信绑定或笼统的恢复方式。单人认证、恢复、冻结与全局解绑全部放在该分区。操作记录只保留在服务端安全审计，不出现在用户界面。
- 成员外卡的批量选择使用内联紧凑胶囊（“选择 / ✓ 已选”），位于姓名学号行左侧、与状态气泡同排，不单独占行；样式复用人员选择器的 `.select-chip` 语言，选中转绿色，禁用态弱化。微型元数据标签（CSV/校验类型等）同样使用紧凑圆角令牌。
- 批量选择框与筛选工具长期显示；重置、全选、反选、清空以及认证码/恢复码生成与撤销同筛选控件并列，不另绘制模块外框。工具按钮使用明确网格，手机每行两个、Pad 每行四个，短文案不得退化为每个按钮独占一行。无可用目标或正在处理时保留按钮并使用原生禁用态，无权限时隐藏。
- 合并账号状态固定按“冻结中、待恢复、已绑定、待激活、未绑定”的优先级取一个结果。冻结、解冻、凭据和解绑操作只更新目标成员及已打开详情，不刷新整页。
- 普通用户的人事信息卡内提供“账号与登录”分区，设备卡片允许身份、组织和岗位自然换行，不能以窄列挤压信息。
- 设备标识来自本地持久化安装标识；标识无法保存时显示“无法识别设备”，不得伪造同一设备或新设备结论。
- 跨组织资料使用全局值原语，唯一规则是“自然人 + 去首尾空格后的字段名 + 完全一致的字段类型”；待审核值不覆盖已生效值，冲突按最新生效时间处理。
