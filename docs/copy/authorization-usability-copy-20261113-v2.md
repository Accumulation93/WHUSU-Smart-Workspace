# 权限任务重构独立语料稿 v2

日期：2026-11-13。独立语言 Agent。状态：结构核实中，尚未批准运行语料实施。本稿不覆盖前轮已实施文字，只有完成设计确认后的逐键表才可接入。

## 对前轮结构的退回

1. 日常分配表单把自定义权限入口放在三步之前，迫使用户先理解两套设置方法。应先完成当前分配任务，再提供独立的复杂设置入口。
2. 委托负责人选择区没有及时说明这是分配资格；到功能权限区才解释，用户已经可能把负责人当作业务权限接收者。结果说明须紧贴负责人区。
3. 授权身份是功能集合，草稿、发布和分配分属不同动作。创建身份页解释这三个动作的关系；日常分配页只展示可使用的已发布身份。
4. “管理员”在选择按钮里容易被理解为一个人的全部账号。对象是具体管理身份，与岗位并列；选择按钮应使用“选择岗位”“选择管理身份”，由上方完整分区标题明确是业务权限接收者还是分配负责人。

## 设计发现的事实缺口

设计 Agent 已反馈：受委托者缺少可分配对象、记录、资料项和期限的完整摘要，只有功能键集合不足以生成合法默认表单。普通岗位可查本人，但不能把仅限管理身份的他人查询入口当作共同功能。这两点须先落实数据与导航设计，不用新文字掩盖接口不支持。

## 待确认的任务结构

- 本人页面分别显示当前工作角色能使用的业务功能，以及是否具有向他人分配权限的资格。
- 分配任务从已获准的分配范围开始，再选接收岗位或管理身份、授权身份及该范围内允许的记录等条件。
- 授权身份管理单独处理草稿、发布和已分配身份的更新影响。
- 超级管理员单独设置分配负责人及其对象、功能、记录、资料项与期限。

以上是任务分离，不要求增加四个平级页签。无分配资格者不显示写入任务；有业务使用权不推导分配资格。是否把多条委托合并必须依据后端事实，不能在语料中自行声称范围可以合并。

最终逐键定稿等待主 Agent 与设计 Agent 确认实际数据和结构。未放行，未修改运行语料。

### 必须保持的结构条件

常用分配不在步骤前展示自定义/禁止切换。所选资格摘要、实际继承的字段与期限不能隐藏在高级区域。动态对象继承条件应可读且只能收窄；指定记录展示业务名称，不能显示内部 ID。本人查询与他人查询用上述不同入口，不能让无查询权限的普通岗位打开空候选框。身份草稿与当前发布版本必须并列区分，发布动作说明影响现有分配。

上述语料已放行实施；实际引用与界面仍待独立复核。若某个继承项允许修改而非只读，应退回补稿，不擅自使用“沿用”掩盖真实交互。

## 查询空态补充

新增 noEffectiveBusinessPermissions 定稿为“当前工作角色暂无可显示的业务权限。”，仅用于本人查询成功后过滤得到空列表。查询其他角色时不能使用“当前工作角色”，需独立键 noInspectedBusinessPermissions：“所选工作角色暂无可显示的业务权限。”。加载失败必须保留错误与重试，不显示这两个空态。

fields=null 不等于可见所有个人信息。查询结果须采用后端真实可用字段投影，不直接复用编辑器 allFields 推断包含受保护信息。具体字段显示待设计确认。

查询规则字段说明新增：effectiveFieldsUnrestricted 为“这条授权未单独限制资料项。”；effectiveFieldsHelp 为“实际可查看或修改的资料仍受当前工作角色和身份信息保护要求限制。”。二者已批准，仅用于查询规则摘要，不改编辑器选择器含义。服务端如提供最终可用字段，显示该投影；未经投影的原始 fields 不得称为实际可用资料项。

## 查询字段最终投影定稿

主 Agent 确认最终事实：supportsFields=true 表示该功能存在字段目录；rule.displayFields 是按被查询工作角色过滤后的实际可显示字段。原 fields 仅保留兼容，不参与查询展示。

新增 effectiveNoVisibleFields：“这条授权没有可显示的资料项。”，已批准，适用于 supportsFields=true 且 displayFields 为空。非空逐项展示 displayFields；不支持字段的功能不展示字段区。此前 effectiveFieldsUnrestricted 不再用于该最终查询路径，不能因原 fields=null 显示不限。effectiveFieldsHelp 可用于说明其他业务保护要求，不替代真实投影。

## 指定记录安全摘要补充批准

根据主 Agent 和设计复核，分配资格不附带业务记录读取权，不能为了名称额外获取审核标题或人事姓名。本轮不增加业务详情目录请求。对只读继承的指定记录，资格业务名称、已有目录资源类型及数量共同构成安全摘要，不展示内部 ID。

新增 recordsSummaryHelp：“这些记录由所选分配资格限定，本次分配不能更换。这里仅显示记录类型和数量。”，已批准用于数量摘要分支。不得将缺少名称解释为当前用户没有业务查看权，因为本页没有逐资源判断该事实。此安全摘要满足本轮可理解性要求，替代此前必须显示业务名称的退回要求；实际绑定与截图待复核。
