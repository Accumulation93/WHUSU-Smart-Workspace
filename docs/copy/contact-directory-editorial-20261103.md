# 通讯录：独立语言审稿与逐项定稿

语言 Agent：`/root/language_editor`。依据 hr-directory-import-context-20261103.md 及 contactDirectory.js。只撰写语料文档。

## 结构审核

有条件批准列表—岗位卡片—联系人详情结构；不批准以下混用继续发布：

1. 复制失败只在复制操作附近显示反馈，不得触发“详情读取失败”而隐藏已读取资料。新增 copyFailed 专用语料。复制成功仅代表剪贴板写入成功，不是保存文件。
2. 规则的查看者、可见人员、补充资料分为三个区。条件摘要须分条件组展示，组内按部门／身份类别／职能组分别列出，不能用斜杠让用户猜“同时满足”还是“任选其一”。同类多个选项任一命中，不同类同岗位同时满足，组间任一命中。
3. 配置人员只有规则管理权，不自动拥有查看权；管理页不得展示完整补充资料值。角色变化或详情权限失效时，返回列表重新读取，不声称人员已删除。
4. 同人多岗位是多张可见岗位卡，“人数”与“岗位数”分别显示；不要因名称相同关联不同自然人。基础信息说明只适用于已获授权的可见岗位。
