# 通知与待办精简：独立语言稿

独立语言角色仅提供本稿，不修改运行语料及业务代码。以 shared/messageFactsView.js 的14类通知和4类待办为范围。

## 放行结构

标题保留真实业务名称；没有名称时保留已有类型标题。说明只表达状态或需要采取的动作；详情行表达步骤、时间、地点和原因。同一事实不能在说明和详情重复。空说明不渲染占位，不把剩余详情压成一句长话。

- 日程有有效时间行时不显示说明；时间只有一端时显示对应开始/结束时间，全天只在日期行标记一次。时间完全缺失时保留 calendarTimeUnknown，不猜开始时间。
- 进展保留已通过步骤、转交步骤；当前步骤与转交步骤编号和名称均一致时只保留转交步骤。不一致时都保留，并明确当前进展。不能凭当前步骤补造历史。
- 驳回状态只说结果，步骤和原因各显示一次。审批通过后不显示仍在处理的步骤。
- 截止提醒说明只表达动作，时间独立显示。事件截止用“截止时间”，只有当前配置时用“当前截止时间”，不混为历史事实。
- 地点与场地相同时只显示一项，不按模糊匹配删除不同内容。组织、岗位属于来源元数据，业务事实不重复搬入说明。
- 通用缺失标题恰好已完整表达状态且无额外事实时可不重复状态说明；不得靠字符串模糊匹配去删用户业务标题或理由。

|---|---|---|

| auditRejected | 申请已被驳回 | 具体步骤、原因由详情行承载 |
| scoringDeadlineAction | 请及时完成评分。 | 截止时间另列 |
| currentDeadlineLabel | 当前截止时间 | 只有当前配置截止事实 |
| auditApproved | 全部审批步骤已完成 | 结果状态 |
| venueApproved | 借用已审批通过 | 结果状态 |
| venueRejected | 借用已被驳回 | 结果状态 |
| venueCancelled | 借用已取消 | 结果状态 |
| profileApproved | 资料修改已通过审核 | 结果状态 |
| profileRejected | 资料修改未通过审核 | 结果状态 |
| scoringStarted | 评分活动已开始 | 结果状态 |
| scoringPublished | 评分结果已发布 | 不重复常规访问权限说明，真实权限仍由接口控制 |
| auditTodoFrom | {name} 提交，待你审批 | 保留提交人；步骤另列 |
| auditTodo | 待你审批 | 无可信姓名 |
| venueTodoFrom | {name} 提交，待你审批 | 借用标题、场地、时间另列 |

短状态不加句号；完整操作说明有句号。动态语句必须由共享语料函数拥有，实施者不得拼句。

## 保留项及边界

迁移四种事件结果与四种当前结果的原文保留，二者事实不同，不因求短去掉“当前”。账号安全两种说明保留。未知进展、未知时间、未知评分数的说明保留，不能把未知改为无。14类通知均保留业务名称或既有类型标题；4类待办保留真实申请人、步骤及评分数量。所有真实理由原样保留，不截断、不改写。无法打开详情的提示属于功能状态，可保留一次，不能同时显示“打开详情查看”这种相反引导。

本稿语言放行，需设计角色确认实际结构可实现后接入；实施后的原生和网页截图仍须独立复审。

## 无法打开详情时的补充放行

不能用“暂时无法打开详情”掩盖缺失业务状态，也不能同时引导用户打开。以下专用键只在 canOpen 为 false 且对应事实不足时使用；存在完整事实时仍直接展示事实，不额外追加未知说明。

| 键 | 定稿 | 情境 |
|---|---|---|
| auditProgressUnavailable | 具体审批步骤暂未确认 | 无可信审批步骤 |
| migrationUnavailable | 资料迁移的处理结果暂未确认 | 无可信事件或当前状态 |
| scoringDeadlineUnavailable | 评分截止时间暂未确认 | 无可信截止时间 |
| calendarTimeUnavailable | 日程时间暂未确认 | 无可信日期或时间 |
| accountSecurityUnavailable | 账号变更的具体情况暂未确认 | 无可信安全变更子类型 |
| unknownNotificationUnavailable | 通知的具体内容暂未确认 | 无已识别类型与有效事实 |

上述均为短状态，无句号。下方仍可保留一次 notificationDetailUnavailable 表达入口不可用，业务信息不足和入口不可用是两个不同事实。

auditProgressStatus“审批有新进展”可保留：它承担概览状态，具体步骤行承担已通过、转交和当前阶段。不得再在该说明中复述步骤名称或序号。如没有任何具体步骤行，应使用未知步骤说明，不以“有新进展”替代信息不足。

calendarTimeUnknown“请查看日程的时间和安排。”本身没有承诺点击，但在不可打开且缺时间时也统一改为上述状态。scoringTodoUnknown不承诺通知详情，可保留其任务动作；若待办没有合法打开入口，不新增点击引导。
