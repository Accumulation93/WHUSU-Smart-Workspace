# 通讯录标签与评分只读状态文案

独立语言 Agent 根据实际页面情境定稿：

| 键 | 文案 | 情境 |
|---|---|---|
| `contactDirectory.filterByTags` | 筛选岗位 | 紧凑筛选入口 |
| `contactDirectory.tagFilterHelp` | 同类任选，不同类别同时符合 | 组合规则说明 |
| `contactDirectory.clearTagFilters` | 清除筛选 | 清除标签 |
| `contactDirectory.tagNoResults` | 没有符合当前标签条件的联系人 | 筛选空态 |
| `home.activityEndedReadOnly` | 活动已结束，可查看已提交内容，但不能提交或修改。 | 已结束评分活动 |
| `home.noVisibleTargets` | 当前工作角色下暂无可查看的评分对象。 | 授权范围内没有评分对象 |

本轮不再使用独立“已选摘要”句。已选数量由入口徽标和分类徽标表达。短标签、按钮、空态和单行规则说明均不使用句末句号；完整状态说明使用句号。
