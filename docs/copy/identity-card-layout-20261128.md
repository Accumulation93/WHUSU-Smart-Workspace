# 身份卡版式调整独立语言复核

2026-11-28。场景核实：`identity_visual_design`；语言复核：`identity_visual_language`；实施与验证：主 Agent。

## 放行范围

本轮不新增运行语料，不修改现有语料值。本人身份卡与公开身份核验的当前时钟改为居中，日期和时分秒分行显示，去掉可见的“当前时间”标题；继续引用 `identityCard.currentTime` 作为无障碍名称。不要设置每秒主动播报的 `aria-live`，避免持续打断读屏。

当前时钟只反映当前时间，不能被解释为每秒重新查询服务端或重新核实身份。本轮不增加“持续核验”“实时有效”等额外描述，不改变原有核验结果、状态和有效期。

| 语料键 | 保留原文 | 使用边界 |
|---|---|---|
| currentTime | 当前时间 | 仅保留为当前逐秒时钟的无障碍名称，不再显示为视觉标题 |
| checkedAt | 核验时间 | 继续作为历史核验时间的可见标题，时间值仍精确到分钟 |
| organization | 组织 | 标签保留，组织名称内容适当放大 |
| department | 部门 | 标签保留，原有可见条件和内容不变 |
| identityCategory | 身份类别 | 保留准确的业务称谓，不简化成含义不明的“身份” |
| functionGroup | 职能组 | 标签保留，空值仍遵循原有可见条件 |
| position | 当前工作角色 | 标签保留，保留无工作角色和历史展示规则 |

资料内容字号调整不扩大身份卡管理开关说明、错误提示或“实时核验”标题。姓名、组织名称、部门名称等业务数据不作为系统文案改写。按钮颜色统一不改变按钮语料及权限含义。
