# 全局控件完整显示审计

日期：2026-09-11。范围是全仓小程序页面、共享组件和弹窗，不只场地借用。

## 审计口径与验收边界

本轮读取全部 WXML/WXSS，使用 `scripts/ui-audit.js` 的逐字符 WXML tokenizer 枚举标准弹窗结构，并检查字段标签截断、正文之外的业务内容、纵向 Flex 收缩及合法几何裁切。当前审计器判定 60 个弹窗，源码显式 `ui-dialog-shell` 声明为 59 处，两者识别口径不同；这不是运行时弹窗组合数，也不是已完成现场测试的数量。后续结构变化以重新扫描结果为准。

本轮代码审计及自动测试不替代微信实际布局、触摸和滚动验证。手机、Pad 竖屏、Pad 横屏的本轮视觉与真机验证尚未完成，不得据此宣称“全局所有设备验收通过”。

## 按钮居中专项（2026-09-11）

人事模板卡片、创建模板与导出按钮仍使用 `display:block`、等于整控件高度的行高；导入确认和管理页底部也有相同的固定高度/行高规则。它们与共享 padding、Pad 后置样式共同作用，导致文字偏下。此前只修编辑器底部三按钮，没有覆盖这些私有类；旧 UI 审计的固定按钮类名单也漏掉了它们。

本次清理上述旧规则，复用共享控件高度、内距和文字行高令牌；共享原生按钮增加 `text-align:center`，标准动作角色显式双轴居中。输入框、选择值、人员卡片正文不改变阅读对齐。`scripts/button-alignment-test.js` 从 WXML 枚举 290 个原生及已声明语义动作按钮，检查声明级偏移、等高行高、截断和不存在的令牌，并有正反例；它不是完整 CSS 级联求值器，也不替代现场验收。

现场事实：已在微信开发者工具 Pad 横屏（1024×768）查看模板库“创建模板、应用模板、编辑、复制、删除”和编辑器“新增资料项、从表格导入、保存人事模板”，文字居中且操作表面完整显示。恢复窗口定位后，Pad 竖屏（768×1024）的模板卡四个操作与编辑器三按钮也已核对；手机（375×667）冷编译后编辑器两个辅助操作各自单行居中、保存独占下一行完整显示。机型切换时出现过旧尺寸过渡画面，未把它算作冷启动结果。未保存、应用或删除生产模板。加载/禁用/超长文案组合及其余页面逐项现场检查仍未全部完成；不得据此宣称全局所有状态现场通过。

### 导出窗口滚动复测

手机现场发现：即使工具栏、全部列和格式已纳入正文，末项仍不能完整滚出。只读 Webview 尺寸检查确认正文宿主实际高度约 420px，原生内部滚动视口仍为 473px；原生内部视口没有跟随外层 Flex 收缩，因而提前认为已到底。增加内容 wrapper 和尾部留白、把宿主改为百分比高度均不能单独解决。

修复使用共享 `ui-dialog-shell--grid`，只对恰好标题、正文、底栏三个直接子级的窗口启用 `auto minmax(0, 1fr) auto`。保留共享视口定位、自然窗口高度和动态上限，不写死正文高度。运行时对照后宿主约 418px、内部视口 400px 加上下内距 18px，尺寸一致；滚轮能到达完整“备注”和 Excel/CSV。源码冷编译后的手机、Pad 竖屏及 Pad 横屏同项均已复测，手机 CSV 切换可操作；横屏标题拖动未移动窗口，固定底栏保持可见。未点击真实资料导出，也未修改生产人事记录。此结论只针对已测窗口，不等于其他复杂变体或真机已自动通过。

## 标准复杂弹窗直接子级枚举

排除标题、正文、底栏与滚动提示后，原结构的额外直接子级集中在以下位置：

- 上述两个 CSV 开关区和错误汇总：属于业务内容，已纳入滚动正文。
- 人事详情的 `detail-loading` 及条件 `modal-body`：加载态，无动态候选列表，不当作裁切故障。
- 场地管理 `rules-tabs`：四个固定短页签，不是无限增长列表；保留固定入口，必须不发生纵向收缩。
- 场地规则编辑 `rule-editor-viewport-limit`：隐藏几何测量哨兵，不是用户控件，不应移为业务正文。

普通弹窗只有正文拥有外层滚动。字段、循环列表、导入来源和可增长说明不能继续成为正文外的固定兄弟。必要的短页签、加载态、滚动提示及测量哨兵须按实际用途审查，不能靠任意类名规避规则。

## 合法裁切与完整查看边界

- CSV 的 `.csv-mapping-sample-text` 是样本摘要；WXML 绑定 `showCsvSampleValue` 并显示完整查看提示。样本可以省略，字段标题和映射选择值不能省略。
- 成员卡的补充资料预览属于摘要，成员详情承接完整内容；不得将摘要样式复用于编辑器字段或选择项标签。
- 手写签名白板与时间轴轨道需要几何裁切，防止笔迹或色块越界；标签、时间手柄及可操作入口必须在裁切轨道外。
- 部门页签有真实横向 `scroll-view` 时，`nowrap` 属于横向滚动布局，不等同于字段不可达。
- 临时拖动影像不是唯一的信息阅读入口。允许其预览省略，不允许正式选择卡片照抄这种样式。

审计不得把所有 `overflow: hidden` 或所有嵌套布局都判为问题。判断标准是完整字段和操作是否存在、能否通过明确滚动或真实详情入口到达；仅有颜色、阴影或省略号不算完整查看入口。
