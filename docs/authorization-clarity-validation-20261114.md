# 权限查询、分配层级与审批详情修复

## 行为与边界

查询默认显示所选工作角色的已授权配置，切换“全部权限”才展示其他目录项；搜索始终保留所选范围。服务端增量返回 granted、blocked、not_granted、unavailable 分类，旧 status/reason 字段继续保留。不改变逐记录业务判权，不把业务入口资格算成已分配权限，也不把未知结果显示为没有权限。

分配列表以工作角色为首层、姓名为辅助信息，权限角色和具体授权逐层展开，未展开内容不创建长列表。用户界面将授权身份改称权限角色，内部字段及人事身份类别不变。具体审批详情删除条件组说明，保留步骤、经办人、意见和审批操作；模板配置及服务端条件判断不变。

设计、语言、实施分别由独立 Agent 完成，设计与语言根据实际浏览器截图复核放行。全局短文案按独立语言稿逐项手写修改，40 个源文件的 282 项批准值逐键匹配；完整确认、长说明及句间拼接保留标点。依据见 `copy/authorization-clarity-copy-20261113.md` 与 `copy/short-copy-punctuation-review-20261113.md`。
