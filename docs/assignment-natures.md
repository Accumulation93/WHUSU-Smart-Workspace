# 岗位性质字典接口

岗位性质为组织独立字典。两端在人事管理页签内使用共享编辑器，旧独立页面与复制深链继续可用。文案唯一来源为 `shared/locales/zh-CN/assignmentNatures.js`。

## 读取与保存

`listAssignmentNatures` 返回当前角色范围内的 `list` 和 `canCreate`。每行包含 `id`、`name`、`description`、`version`、`canUpdate`、`canDelete`、`deleteRestrictionCode`。描述为空统一返回空字符串；兼容字段`deleteRestrictionCode`固定为空。所有岗位性质采用同一规则，初始编号不具备特殊保护。`canDelete` 表示授权资格，不代表引用校验已通过。

`saveAssignmentNature` 接收名称、新建可省略编号、编辑必须传编号和版本。`description` 可选，类型为字符串，上限2000个Unicode码点，保留原换行。编辑时省略该字段保留原描述；显式空字符串清空；新建省略时保存空描述。非法类型或超长返回 `assignment_nature_description_invalid`，版本冲突不覆盖记录。所有写入在事务内复核当前组织和行级授权。

## 删除与复制

`deleteAssignmentNature` 接收编号与版本。岗位、规则或历史引用返回 `assignment_nature_in_use`，不解除既有引用保护。前端有删除权限时显示入口，所有性质均先确认再提交，由服务端在事务内复核权限、组织、版本与引用。

`20261111010000_assignment_nature_initialization.sql` 为组织授权状态增加初始化标记，已有组织标记完成。新组织只初始化一次，删除单项或全部选项后再次初始化也不补回；初始化与组织创建同事务，失败回滚。旧迁移由账本管理，不人工重放已执行的初始数据迁移。旧格式人员同步使用已有岗位的真实岗位性质，新建旧格式岗位仅在默认性质仍存在时建立，缺失时明确拒绝并回滚，不自动重建已删性质。

跨组织复制的新载荷携带描述并在目标独立保存。历史载荷缺少描述时保持原结构参与摘要校验，避免增加空字段导致旧分享或草稿失效；实际创建时补空描述。

## 迁移与验证

`20261110190000_assignment_nature_description.sql` 通过信息表检查新增可空TEXT列，使用INSTANT，重复执行不重写数据。授权隔离数据库测试执行两遍迁移，并通过真实HTTP参数保存、回读、省略保留、显式清空、边界与删除保护。组织复制隔离测试验证新描述及旧载荷摘要兼容。

网页两份专项覆盖三档浏览器，包括描述多行保存后重开、初始性质按普通确认删除并回读列表。浏览器使用模拟响应，数据库保存证据来自独立HTTP集成。微信编译、原生操作及实体设备结果由主任务单独登记。
