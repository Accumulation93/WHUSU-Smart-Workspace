## 普通正文自然高度接入

逐处手写修改22处滚动正文：venueManage的8处（场地编辑、规则列表、活动详情、借用详情、管理员借用、事由管理、条件多选、审批），venueBooking的4处（活动详情、借用详情、借用表单、审批），我的借用与待审批各1处，日程的退出/取消、订阅与规则删除3处，消息2处，门户跨组织确认、登录表单、管理员权限各1处。规则编辑由主代理接入，未重复修改。两处时间表双向专业滚动区不套普通正文布局。

所有上述宿主声明`ui-dialog-scroll--natural`，内容单独承接`ui-dialog-scroll-content`，避免原生滚动视口纵向内边距重复计入可用高度。活动详情移除独立测量高度、父页面回调及组件只为高度服务的查询；周期说明和参会人加载逻辑保留。日程3处短确认保留共享grid结构，由共享自然高度负责短内容收缩。未修改`app.wxss`、数据库、权限和项目配置。
