## 身份发布、历史版本和权限查询

身份保存按钮为“保存草稿”；草稿不能分配，发布按钮为“发布身份”，最终为“确认发布”。说明：“发布后，已使用这个身份的岗位会同步更新权限。”版本入口为“历史版本”，动作为“恢复此版本／确认恢复”；恢复也先展示变化。编辑身份仍叫“编辑”，不能误写成调整某个人的权限。

权限查询入口为“选择岗位／选择管理员”，未选时显示“当前工作角色”。结果采用“已授权／未授权／按范围生效／还需满足办理条件”；理由说明指定审批人、数据范围等仍在办理时核对，不把授权等同于可以代审。不存在的选项显示“选项已失效”，读取失败明确重试。

管理员分配权放在全部授权中，标题“谁能分配权限”；字段“选择分配人／可以分配给谁／可以分配哪些权限”。说明：“设置管理员能把哪些权限分配给哪些岗位，不改变已分配的权限。”撤销确认说明已有授权仍保留。

## 状态、失败和按钮视觉

加载、保存、发布、复制分别使用“正在加载权限／正在保存权限／正在发布身份／正在复制”。必填提示明确指出人员、权限、管理范围；冲突提示刷新后重新确认；无权、失效来源、同名配置与关联项缺失分别说明，不统一写成“失败”。现有保护性确认和错误含义完整保留。

新增、最终保存、发布及确认复制使用主按钮；编辑、调整权限、复制、返回和更多设置使用浅色次按钮；撤销授权、删除、撤销分享使用危险按钮。允许／禁止和范围是选项，选中使用浅蓝背景与蓝色边框，不伪装成主操作。每行最多两项普通操作，按钮间有固定语义间距；禁用状态保持可辨识。逐页检查权限首页、编辑、变更确认、组织复制四页签和详情，不靠新增一条编辑色覆盖所有控件。
