# 审核签署工作区交接

## 当前实现

小程序与网页使用独立签署页，文件填满统一顶栏以下的剩余空间。顶部包含浏览、移动、画笔模式、六个图标工具和笔色工具；本专业页按用户明确要求不显示身份 Hero。普通业务页的身份卡要求保持不变。

`shared/auditInk.js` 定义连续曲线、逐笔颜色、局部擦除、清空、撤销和文件相机。每次落笔使用一次路径和描边，透明导出共用同一模型。`shared/auditSignatureGeometry.js` 负责实际宽度、旋转和边界；`shared/auditStepView.js` 只按实际审批事实解释步骤。

草稿只在账号与工作角色对应的内存中保存，绑定申请、轮次、步骤及附件版本。确认返回只保存步骤编辑，不提交审批；重进可立即撤销。不同附件隔离，PDF 各页归同一附件；取消恢复进入前的历史。正式处理成功后锁定，回读失败只重读。刷新、退出、重启和工作角色变化清除草稿。

小程序预览优先由内存中的图片直接进入 Canvas；视图只收到短预览键，不通过 setData 传输完整 PNG。真正的图片和签章源在工作区内存中读取。部分运行时不支持直接解码时，才尝试限定预览文件；过期预览和本工作区临时文件由 `auditPreviewFiles` 管理，原附件与上传文件不参与清理。导出的临时 PNG 读取完后释放。

## 审批、目录和报告

用户仍调用 `approveStep`，指定下一步岗位仍提交人员与岗位两组编号。印章目录调用 `listMyStamps` 的轻量参数，选中后由 `getMyStampImage` 按当前岗位重新检查授权；正式审批再次校验。加载、空目录、失败和图片读取分别展示。

管理模板、电子印章、申请目录和验证授权使用原有写接口。新增 `getAuditTemplateEditorData` 与 `listAuditVerificationCandidates` 两个组织内只读目录，分别由 `audit.templates` 与 `audit.verification` 控制。目录仅返回名称及选择需要的岗位字段，不返回学号；人员选择复用共享选择器。

撤回申请默认显示撤回结果，之前的实际审批与签章进入可展开历史。当前待处理步骤显示时钟和处理中，未来才显示未到达；处理人按事件与处理时资料显示，姓名未知时不显示岗位。默认验签先显示结果、文件与经办人；专业检查、摘要值及证书在独立报告中折叠，必要失败项仍在摘要显示。

## 数据与发布

迁移 `20261014143000_audit_signature_geometry_v3.sql` 增加可空 `width_ratio`，重复执行保持一致。带比例的材料使用哈希 v3；旧 v1/v2 保持原验证，CMS 凭证仍使用 v2。签名图片上限仍为 2 MiB。不得改写历史文件、证书或审批事实。

已有未提交的人事导入属于其他任务。共用 app.json、可信路由、同步清单、权限目录和故障登记必须只暂存签署相关变化，不将人事代码或迁移混入本批。

## 验证事实与剩余项

- 新工具栏版本的手机浏览器 8 项签署交互通过，另有 3 档浏览器布局测试通过；布局测试逐项覆盖 310×650、390×844、768×1024、1280×720，文件区域超过顶栏下空间的 50%，底部按钮可见且无横向溢出。
- 原生运行中强制持久文件写入全部失败，同一份实际 PDF 仍加载成功，预览写入次数为 0；画布曾测得 352×456px。Windows Computer Use 实际鼠标拖动产生一条连续黑线，透明导出为 160×12px，618 个黑色像素、0 个蓝色像素及 1302 个透明像素。测试没有提交生产审批。
- 原生实际点击确认返回后，申请仍可审批，步骤历史 cursor 为 1 且导出材料为 1；第二次进入立即显示可撤销，实际点击撤销后 cursor 为 0、重做可用，画布中的笔画消失。验证后已经恢复测试前内存草稿，没有提交或更改生产审批。
- 最终浏览器实际产生的审批参数已经在隔离 HTTP/MySQL 中成功批准并回读，最终 PDF 平台验签通过；另覆盖材料 v3、旧材料 v2、授权撤销、非法参数整单不写及组织边界。迁移连续执行两遍通过。完整回归为 501 项网页测试、186 个服务端测试文件、36 项专项检查及三档 87 项视觉取值检查全部通过。
- 最终源码通过官方微信 CLI 主包与 6 个分包真实预览编译，总计 2369744 字节；主包 581476 字节，最大 scoring 分包 947326 字节，均小于单包 2 MiB。生产签署密钥及独立恢复备份检查 ready；CI/生产部署仍待本批提交后的结果核对。手机、Pad 竖屏、Pad 横屏实体设备未完成现场验证；微信正式版本尚未发布。不能把自动化视口、编译或本地源码更新描述为正式发布。
