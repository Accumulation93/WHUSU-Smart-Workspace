# 权限分配入口与操作说明修复验证

## 实施范围

普通岗位只有获得当前有效分配委托后才有权限管理入口；同一人的其他岗位不继承。管理员给普通岗位分配功能权限仍通过共享岗位选择器。三项主任务为分配权限、授权身份、查询权限，分配资格单独放在高级管理区。语料设计、独立写作和实施记录分别见 `docs/copy/authorization-usability-context-20261113.md`、`docs/copy/authorization-usability-copy-20261113.md`。

普通岗位委托不包含治理能力；不能转授分配资格，不能修改命中本人的直接或动态授权。授权身份发布、恢复同样逐条检查关联规则。动态目标范围不变成永久指定岗位授权，候选列表与保存支持的目标形式一致。仅有查询资格的用户直接打开三种编辑地址时，均不读取配置候选、不展示编辑表单。
