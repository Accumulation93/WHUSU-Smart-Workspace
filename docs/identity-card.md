# 身份卡与匿名核验

门户新增独立身份卡子应用，两端Hero非交互区域进入本人身份卡，工作角色切换保留原动作并隔离事件。本人身份卡读取认证账号当前工作角色，不接受客户端人员或组织指定。管理角色显示管理权限有效，不冒充在职岗位。

当前界面：本人身份卡顶部直接复用共享workspace-hero/WorkspaceHero，保留下方资料与双码、原图操作；不再使用独立深色凭证头。公开核验页使用浅蓝结果卡，突出核验结果与被核验人姓名，不显示查看者当前角色；有效时按钮为“刷新”，失败或失效时为“重试”。9项三档浏览器检查与87项视觉检查通过，实体设备尚未现场验证。

两种码均请求透明背景：标准二维码保留4模块静区、黑色不透明码点；微信小程序码使用is_hyaline=true与纯黑line_color。页面图片表面不设置独立底色，直接透出身份卡原有浅色渐变，保存原图不合并页面背景。标准码像素透明度、不同尺寸浅底及真实浏览器截图均执行解码；微信原生识别需现场确认，不用标准二维码解码器冒充小程序码识别。

## 接口与公开范围

- `getMyIdentityCard`：登录读取当前姓名、组织、岗位、状态。
- `createMyIdentityCardCode`：登录为当前角色生成微信小程序码，可选envVersion仅允许release/trial/develop；小程序跟随运行版本，网页默认release。
- `verifyIdentityCard`：匿名POST，token为32位随机十六进制值，只返回valid及四项展示信息、核验时间。无效、过期、冻结、岗位撤销均不返回人员资料。不返回学号、联系方式、账号/人员/组织/岗位内部编号。

二维码24小时有效，数据库仅存SHA-256摘要、所属账号组织及工作角色。公开查询凭128位随机码定位，再用统一身份模型重新读取权威账号与工作角色；不回退到其他岗位，不把截图当本人证明。响应禁止缓存。公开核验每IP每分钟60次，生成每账号每分钟6次。微信access_token有界内存复用及并发合并，密钥不输出日志。

小程序码调用微信stable_token和getwxacodeunlimit，固定落地`subpackages/org/pages/identityCard/identityCard`，PNG/JPEG均按实际字节识别。生成失败不保存核验记录；生成后再次复核角色。账号永久删除通过外键清理核验记录，过期记录在本人下一次生成时清理。小程序离页清除私有成图文件，页面隐藏及角色变化丢弃迟到结果。

## 发布与验证边界

工作台内扫一扫显式启用 qrCode、barCode、wxCode，支持相机和相册。微信返回本站已注册的 path 时，直接在当前小程序内 navigateTo：开发版仍在开发版，体验版仍在体验版，正式版仍在正式版，不通过外部链接重新打开。标准核验二维码也转换为当前包内身份页。微信外部扫一扫不属于这条内部导航，仍由生成时 env_version 控制启动版本。未知或未注册路径不自动打开。

新增在线建表迁移`20261019120000_identity_cards.sql`，不修改已有业务表。隔离MySQL测试迁移重复执行、实际前端参数的生成与匿名HTTP核验、公开字段、组织边界、过期及冻结；微信API图片使用测试替身，不代表微信官方服务现场调用成功。小程序页面与API、Hero及门户专项测试和真实微信全包编译分别记录。

微信正式版必须另外上传、审核及发布新页面后，release码才能在用户正式版落地；服务端上线不等于微信正式版发布。develop/trial码仍受微信对应版本访问资格限制。实体手机扫码及Pad两方向未现场验证时不得称为全部完成。

2026-10-19 相册识别专项：生产微信接口实际返回完整小程序码，未重现用户手机原生识别失败，不能把scanType默认二维码参数认定为根因。新增同一随机令牌的标准核验二维码，默认展示；小程序码保留切换，二者均1024像素。标准码内容固定为本站HTTPS核验地址，工作台扫一扫严格匹配主机、路径及32位令牌后在小程序内打开，其他链接保持原有非自动跳转行为。小程序与网页的查看/保存原图复用统一文件输出接口。卡面采用独立凭证卡头、盾牌和细线底纹，删除冗长提示；装饰不作为防复制证明，真实有效性仍由服务端实时检查。旧客户端继续读取image，新增verificationImage为可选兼容字段，无迁移。
