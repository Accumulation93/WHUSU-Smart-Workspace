## 自然 Grid 的结构接入

主任务随后在同一借用规则窗口观察到 Flex 正文外框527.175px与原生内部视口不同步，改为自然Grid后最大滚动量由32.8px增至59.2px，末按钮底707.1px小于正文底723.2px。因此不能仅凭移入padding后的单个场景就宣称Flex已普遍可靠。
