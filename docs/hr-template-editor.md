# 人事模板查看与编辑

## 交互契约

- 模板库卡片内查看字段，字段预览展示真实类型；序列同时展示选项。预览只使用已加载目录，不重复请求。
- 预览字段行复用当前组织补充资料快照的排版：序号、字段名、类型标签、必填标签和序列选项规则。
- 编辑器在当前模板卡片内呈现，不放在整个列表顶部；具备管理权限时“查看/编辑”合并为一个入口，仅选择权限用户保留只读“查看字段”入口。一次只展开一个字段的设置，其余保留简洁摘要。
- 新增与编辑共用同一个编辑器（现已拆成独立组件 `components/hrTemplateEditor/`，页面只保留使用处与处理逻辑），不复制两套表单。字段列表由页面滚动，不借用评分列表的滚动回调；操作栏吸底常驻，字段多时也不必翻到底找保存。
- 类型、数字规则和填写方式的原生 picker 必须绑定当前值对应下标。显示标签与原生选择状态来自同一枚举，禁止打开已保存的序列字段却默认选中“文本”。
- 字段顺序可以调整：每行提供“上移 / 下移”，并支持长按 `≡` 手柄拖动排序（松手落位、拖到边缘自动翻页）；保存顺序就是成员端看到的顺序。顺序变化只改提交数组，服务端按数组先后落库。
- 展开状态按字段编号记录，允许同时展开多个字段；排序、删除后仍停在同一个字段上，打开模板时默认全部收起。
- 序列可选内容使用多行输入区（一行一个、忽略空行）：高度由选项条数决定，**5 行起步、最多 12 行，超过就在框内滚动**，手机与 Pad 分别使用受控 rpx/px 高度。行数通过内联样式变量传给组件，组件里必须用三级类选择器 + `!important` 设高——全局 `.field-textarea` 在 Pad 档带 `height: auto !important`，否则又会被压回一行；选项框不得再依赖 `auto-height`。模板说明同样有最小行数兜底；两个多行输入都带键盘间距，手机上键盘弹起不遮挡正在输入的行。
- 输入区下方按“一行一条”列出选项：文字 + 排序控件 + 删除。默认只列前 6 条，超过时显示“展开全部（共 N 项）”，展开后可“收起选项”。排序控件（`≡` 拖动、`↑`、`↓`）只在展开全部时出现，首尾自动禁用；收起态只保留删除，并提示“展开后可调整顺序”。删除、清理重复项与调整顺序都算“有未保存的修改”，调整后的顺序即成员端下拉顺序。
- 折叠状态与“查看资料项”预览只显示前两个选项加“共 N 项”，不把整段选项铺开。
- 保存前先在本地指出问题：模板名必填，资料项名必填且不重名，序列至少一个选项，长度/位数/数值必须是数字且最小值不大于最大值。出问题的字段行标红并写一句原因，顶部汇总“有 N 处需要修改”，并自动滚到第一处；服务端校验照旧保留，返回的原因能对上字段时同样标到行上。
- 有未保存修改时，标题行显示提示、点取消要先确认、离开页面走原生离页确认；删除资料项必须二次确认并写明是哪一项。展开、拖动、查看都不算修改。
- 从表格导入资料项时按列名认类型（手机号 / 邮箱 / 日期 / 日期时间 / 数字）；名称含“号、证、卡、码”的一律按文本，避免学号被当成数字；名称没有信号但整列都是数字的按数字，其余按文本，序列仍按文本，导入后都能再改。导入确认框除列名预览外给出识别结果。
- 应用模板时，旧文本字段可映射到日期、手机号、邮箱等类型；服务端会识别带时区的日期、`+86`/空格/连字符手机号以及邮箱，并在落库时规范化为目标类型格式。
- 编辑使用独立草稿；展开、收起、切换字段和取消不发保存请求。编辑中禁止打开第二份模板草稿，保存失败保留原稿。
- 模板库保存与应用到组织仍为两步。保存不覆盖任何组织的已生效资料设置；应用前保留字段匹配、类型校验和明确确认。
- 手机与 Pad 使用同一语义结构、共享字号与高度令牌，字段标题可完整换行。操作按钮文字居中，辅助动作与主保存动作保持层级。

## 验证

`scripts/hr-template-save-continuation-test.js` 验证六类字段标签/下标、按编号展开与多字段同时展开、上移下移与拖动落位的提交顺序、选项框行数计算（0/1→5 行、7→7 行、20→12 行）、选项列表默认前 6 条与展开收起、选项按按钮与拖动调整顺序后的提交顺序、未保存提醒与放弃确认、删除二次确认、选项解析与重复项清理、导入按列名与内容认类型、保存前就地校验与滚动定位、取消不写回、真实保存参数和保存后的应用确认。组件侧由 `miniprogram/subpackages/scoring/pages/admin/tests/hrTemplateEditorDrag.test.js` 验证资料项与选项两种行的长按进入拖动、插入位置计算、松手上报、边缘自动翻页，以及选项拖动只按本字段的行比较；`server/test/hrProfileTemplateSaveRoundTrip.test.js` 验证数字/序列及选项以及顺序的服务端保存回读。

静态测试不能替代手机、Pad 竖屏、Pad 横屏实际展开、原生选择器和滚动验收。现场未完成时不得宣称全部验收通过。
