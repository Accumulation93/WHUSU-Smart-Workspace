# 人事模板查看与编辑

## 交互契约

- 模板库卡片内查看字段，字段预览展示真实类型；序列同时展示选项。预览只使用已加载目录，不重复请求。
- 编辑器在当前模板卡片内呈现，不放在整个列表顶部。预览中的“展开编辑”直接定位该字段；一次只展开一个字段的设置，其余保留简洁摘要。
- 新增与编辑共用 `hr-template-inline-editor`，不复制两套表单。字段列表由页面滚动，不借用评分列表的滚动回调。
- 类型、数字规则和填写方式的原生 picker 必须绑定当前值对应下标。显示标签与原生选择状态来自同一枚举，禁止打开已保存的序列字段却默认选中“文本”。
- 编辑使用独立草稿；展开、收起、切换字段和取消不发保存请求。编辑中禁止打开第二份模板草稿，保存失败保留原稿。
- 模板库保存与应用到组织仍为两步。保存不覆盖任何组织的已生效资料设置；应用前保留字段匹配、类型校验和明确确认。
- 手机与 Pad 使用同一语义结构、共享字号与高度令牌，字段标题可完整换行。操作按钮文字居中，辅助动作与主保存动作保持层级。

## 验证

`scripts/hr-template-save-continuation-test.js` 验证六类字段标签/下标、预览展开、取消不写回、真实保存参数和保存后的应用确认；`server/test/hrProfileTemplateSaveRoundTrip.test.js` 验证数字/序列及选项的服务端保存回读。

静态测试不能替代手机、Pad 竖屏、Pad 横屏实际展开、原生选择器和滚动验收。现场未完成时不得宣称全部验收通过。
