## 一、一致性系数（CI_r）分析

### 方法说明

对每位评分人 r，按被评人类别（目标身份）分组，仅分析**所有预期目标均已评价完毕**的完整类别。对评分人在该类别下所有评分记录的总分（所有模板得分之和），计算其标准差 σ_r 和平均值 μ_r，得到一致性系数 CI_r = σ_r / μ_r。

CI_r 衡量评分人在同一类被评人上的评分区分度——CI_r 越低，说明对不同被评人打出的分数越接近，评分区分度越差。

**异常判定标准**：
- n ≥ 8 且 CI_r ≤ 0.015：评分差异过小，可能存在趋同化填写
- n < 8 且 CI_r ≤ 0.01：样本较少时要求更严格

## 二、极端分值异常分析

### 方法说明

仅分析完整类别中的评分记录。对每个评分模板，分析评分分布（均值 μ、标准差 σ），检测以下异常模式：
1. **天花板效应**：评分人对某模板的所有评分均为满分（零方差）
2. **地板效应**：所有评分均为 0 分（零方差）
3. **显著均值偏离**：评分人平均分偏离全局分布 z-score > 3.0
4. **单条极端值**：单条评分修正 z-score（基于 MAD）> 3.5 且绝对偏差 ≥ 满分的 15%
